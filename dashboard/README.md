# Dashboard

This folder contains all Power BI dashboard assets developed for the MedTrack DV – Hospital Operations & Patient Analytics Dashboard project.

## Contents

- **dashboard_storyboard.pdf**
  - Dashboard layout and design plan
  - KPI selection
  - Visual planning
  - Navigation flow
  - User interaction design

- **MedTrack_Dashboard.pbix**
  - Power BI dashboard file
  - Interactive visualizations
  - KPI cards
  - Charts and filters
  - Business insights

## Tools Used

- Microsoft Power BI
- Power Query
- DAX
- Data Modeling
